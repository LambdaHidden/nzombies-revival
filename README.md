nZombies Revival
========

A revival of the original nZombies gamemode.
This is for those "classic nZombies enthusiasts" that want to relive the old nZombies experience.

This also includes modifications to fix up and improve the gamemode without drastically changing it to keep it faithful to the original.

Get the gamemode here (content packs listed in required items):
https://steamcommunity.com/sharedfiles/filedetails/?id=3626312419

A collection with content and weapon packs for the gamemode:
https://steamcommunity.com/sharedfiles/filedetails/?id=3626484548

There still might be some bugs in this due to its age, though I might be able to fix it in the future.
If you have any fixes you can provide, feel free to do a pull request.

Special thanks to Hidden, Dj_Nathan_, and Global for providing a patched version for me to work off of.
